# One-Day Life Reset Protocol

A structured, identity-level reflection and pattern-interruption protocol designed to surface unconscious goals, dismantle limiting identities, and orient action toward meaningful long-term change.

This repository contains a **one-day guided process** derived from a long-form essay on behavior change, psychology, and identity formation.

---

## What This Is

- Not a productivity system  
- Not a motivational exercise  
- Not goal-setting in the traditional sense  

This is a **diagnostic and reorientation protocol** intended to be completed in one focused day, with effects that compound over time.

---

## Repository Contents

- `Poster.md`  
  One-page wall summary of the core ideas and mental models.

- `Homework.md`  
  The complete one-day protocol, including:
  - Morning psychological excavation (anti-vision & vision)
  - Daytime pattern interruption prompts
  - Evening synthesis and goal lenses
  - Structured space for typed responses

---

## How to Use

1. Read `Poster.md` once for context.
2. Set aside a full day.
3. Follow `Homework.md` in order:
   - Morning: write honestly and slowly.
   - Throughout the day: use reminders and pattern interrupts.
   - Evening: synthesize, compress, and commit.
4. Do not rush. Do not outsource the thinking.

This is meant to be revisited periodically, not “completed” once.
